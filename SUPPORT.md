# Get help

**Check the common fixes**

Start with [Troubleshooting](docs/troubleshooting.md). For connection problems, see [MCP authentication](docs/authentication.md).

**Report a bug or request a feature**

Open an issue in [rhythm-labs-inc/ritmo](https://github.com/rhythm-labs-inc/ritmo/issues). Setup questions and feedback on confusing steps are welcome too.

For a bug report, include:

- Your Ritmo and Node versions, and operating system.
- The command you ran and the host profile you selected.
- What you expected and what happened.
- A small example that reproduces the problem, with secrets and private data removed.
- Whether you saw it in the local simulator or in ChatGPT or another host.

Use [private security reporting](SECURITY.md) for vulnerabilities.

**Support and updates**

Rhythm Labs Inc. maintains Ritmo. Support is provided as time allows, with no guaranteed response time.

Check the [changelog](CHANGELOG.md) when updating. Before version 1.0, the library API may change between minor releases. Pin a tested version if another application imports Ritmo. See [migration](docs/migration.md) for older AppRhythm configurations and [release guidance](docs/releasing.md#upgrade-and-rollback) for rollback.
