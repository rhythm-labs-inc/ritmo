# Report a security issue

Use [GitHub's private vulnerability report form](https://github.com/rhythm-labs-inc/ritmo/security/advisories/new). Rhythm Labs Inc. reviews these reports. Do not post exploit details or credentials in public issues.

**Include enough detail to reproduce it**

- The affected Ritmo version and operating system.
- What an attacker could do.
- A minimal reproduction using test data.
- Any workaround you found.

Remove real tokens, personal data, and customer payloads. Response times are not guaranteed. Once releases are published, routine security fixes target the latest release.

**When testing MCP apps**

Ritmo can execute tools on your MCP server. Use appropriate test data and permissions. Your server must enforce its own authentication and authorization; widget previews and validation findings do not replace those controls.
